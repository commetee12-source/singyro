## 배포
README에 따르면 현재 Netlify는 Git 저장소 자동배포가 아닌 수동 업로드 방식. GitHub 변경만으로 공개 배포 완료로 표시하면 안 됨. 빌드 후 기존 functions 디렉터리를 포함하여 Netlify 배포해야 함. 개인정보·토큰·내부자료를 public 폴더에 넣지 않음.

## 검증 환경
로컬 샌드박스의 의존성 파일 접근 제한으로 전체 빌드가 확인되지 않아 GitHub Actions에서 npm ci·타입 검사 포함 npm run build·자료 ID 검사를 실행한다. 성공 결과 확인 전 운영배포하지 않는다. 배포 아티팩트에는 dist, netlify/functions, netlify.toml을 포함한다.
