# 디자인과 구조

서울시교육청 교육행정직 신규자가 모르는 업무를 검색하고 첫 달을 준비하는 개인 업무 안내서. 참고 사이트의 검색·상황별 탐색·출처 표시·AI 질문문 복사 방식에서 출발하되, 내용은 교육행정 업무로 새로 작성한다.

- 색상: 제목 남색 #15324f, 주요 동작 청록 #087f84, 연한 민트 #eff8f5, 종이 #f7fafb, 보조 노랑 #f5ce58. 참고 사이트와 구분되도록 기존 보라·라벤더 중심 색상을 교체한다. 첨부된 기관 이미지의 원래 색상은 유지한다.
- 글꼴: 자체 번들 Noto Sans KR Variable. 제목 28~~38px, 본문 14~~16px. 지나치게 얇은 글자와 긴 행을 피한다.
- 배치: 왼쪽 고정 길잡이 메뉴 / 상단 검색 / 첫걸음 소개 / 상황별 바로가기 / 업무 분야 / 첫 출근 체크리스트. 모바일에서는 접을 수 있는 메뉴와 단일 열을 사용한다.
- 고유 요소: 왼쪽 메뉴 상단의 서울특별시교육청 로고, 첫 화면의 자라나·열리미 환영 이미지, 서울교육방향 배너. 본문 상단 바에는 현재 페이지 이름을 표시한다. 배너를 누르면 반응형 포스터와 PDF 다운로드를 제공한다. 근거 상태는 색과 글자를 함께 표시한다.
- 검토: 범용 대시보드의 통계 카드 대신 실제 업무 분야와 첫 달 체크리스트를 배치한다. 근거를 확인하지 않은 자료에 검증 완료 표시를 하지 않는다.

UI는 src/App.tsx, src/components.tsx, src/styles.css. 서울교육 브랜드 색상·반응형 배치는 src/brand.css, 로고·캐릭터·교육방향 컴포넌트와 이미지 경로는 src/SeoulBrand.tsx에 분리한다. 업무 내용은 src/data.ts, 공통 자료 목록은 public/manuals.json, 로컬 저장은 src/storage.ts로 분리한다. 디자인 변경 시 자료와 체크리스트 ID를 유지하면 저장 상태가 이어진다.
