# 에듀파인 따라하기 — 독립 메뉴

추가일: 2026-09-19. 주소: `/#edufine-access`.

기존 홈, `/#edufine` 용어사전, 자료실과 공통 디자인을 유지하고 왼쪽에 **에듀파인 따라하기** 메뉴를 추가했다. `EdufinePage.tsx`에는 지출 분야의 시스템 진입 카드를 추가하고 화면 자료 확인 범위 문구를 갱신했다. 용어·질문 요령·관련 자료는 유지하며 `edufine.ts` 데이터는 변경하지 않았다. `App.tsx`에는 새 화면 import·메뉴·경로 렌더링과 업무시스템 분야의 바로가기를, `types.ts`에는 경로 타입을 추가했다.

주 진입 경로: **K-에듀파인 → 지출 → 지출관리시스템 → 지출관리 따라하기 → 업무 선택**. 왼쪽 **에듀파인 따라하기** 메뉴 또는 홈 **나이스·K-에듀파인** 분야 → **에듀파인 따라하기 열기**에서도 진입한다. 업무 길잡이의 **업무시스템** 분야 탭에서도 같은 바로가기가 표시된다. 기존 길잡이 5건은 그대로 유지한다.

수입관리 확장: **에듀파인 따라하기** 메뉴 안에 **수입관리시스템**을 추가했다. 수입·지출 업무를 같은 방식으로 연습하며 시스템별 자료·검색·진도는 분리한다. 자세한 내용은 [수입관리 추가 문서](EDUFINE-INCOME.md)를 참고한다.

예산관리 확장: 같은 메뉴 안에 **예산관리시스템**을 추가했다. 성립전예산·추가경정예산·이전용·예비비 등의 공개 자료를 연결하며, [예산관리 추가 문서](EDUFINE-BUDGET.md)에 출처와 검증 결과를 기록한다.

사업관리 확장: 같은 메뉴 안에 **사업관리시스템**을 추가했다. 사업관리카드 조회·담당자 지정·세부항목 관리 등의 공개 자료를 연결하며, [사업관리 추가 문서](EDUFINE-PROJECT.md)에 자료 확인 범위와 검증 결과를 기록한다.

## 지출관리시스템 따라하기

- 목록 주소: `/#edufine-access?activity=expense`. 업무 직접 주소 예: `/#edufine-access?activity=expense_008`(품의등록). 처음 접속 안내: `/#edufine-access?activity=login`.
- [AI-SEN 공개 지출관리 카탈로그](https://chatbot.aisen.store/data/catalogs/expense.json)를 실행 중 불러온다. 2026-09-19 확인 시 88개 업무이며, 분류·검색·수록 단계 수를 제공한다. 원본 변경 시 목록도 바뀔 수 있다.
- 원본 사이트의 공개 매뉴얼 이미지를 직접 표시한다. 원격 스크립트를 실행하지 않으며 HTML을 삽입하지 않는다. 이미지 경로는 해당 출처의 `scenes/expense_p숫자.png`만 허용한다. 요청에 자격증명과 리퍼러를 포함하지 않는다.
- 화면 표시 클릭 또는 ‘확인하고 다음’으로 학습 단계를 확인한다. 이전·다음 설명과 전체 단계 선택은 확인 수를 늘리지 않는다. 마지막 단계에서 확인하면 건너뛴 미확인 단계로 돌아간다. 모든 단계 확인 후 완료 안내와 다시 연습을 제공한다.
- 단계 번호·페이지는 원문을 보존한다. 일부 카탈로그에는 중간 단계가 빠져 있으므로 완전한 전체 업무 절차라고 표시하지 않는다. 카탈로그 페이지 번호는 이미지에 인쇄된 쪽수와 다를 수 있다.
- 확대·이미지 원본 열기·참고사항·전체 단계 목록 제공. 인터넷·출처 서버에 의존하며, 불러오기 실패 시 재시도와 원본 사이트 링크를 표시한다. 이미지 실패 시 텍스트 설명을 유지한다.
- 지출 업무의 연습 확인은 현재 화면에서만 유지한다. 실제 업무 시스템과 연결되지 않으며 저장·결재·이체를 수행하지 않는다.

관련 파일: `src/EdufineWalkthroughPage.tsx`, `src/edufine-workflows.ts`, `src/edufine-workflows.css`, `scripts/edufine-workflows.test.mjs`.

## 처음 접속 안내 기능

- 업무망에서 접속: 준비 → 업무포털 → 인증서 로그인 → K-에듀파인 선택 → 소속·업무 확인(5단계).
- 집·외부에서 접속: 준비 → EVPN 승인 → EVPN 로그인 → VPN 연결 확인 → 이후 공통 단계(8단계).
- 학습용 화면의 클릭 연습과 실제 화면을 본 뒤 직접 표시하는 확인 기록을 구분한다. 연습 버튼과 ‘다음 설명’은 완료 수를 늘리지 않는다.
- 단계별 도움말, 공식 사이트 새 창 링크, 문제 해결 안내, 출처·확인 범위를 제공한다.
- ‘옆에 두고 보기’는 440px 안에 설명을 모으며, 브라우저 창을 실제 업무 화면 옆에 놓아 사용한다.
- 각 경로의 확인 기록을 별도로 저장하고 새로 방문하면 첫 미완료 단계에서 시작한다. 마지막 단계에서 확인하면 앞서 건너뛴 단계로 돌아간다.
- 계정·인증서·비밀번호를 입력받지 않으며 실제 업무 시스템과 통신하거나 접속 상태를 감지하지 않는다.

## 근거와 확인 범위

확인일: 2026-09-19.

1. [서울교육청 EVPN 공식 페이지](https://evpn.sen.go.kr/custom/index.html): 공식 업무포털·K-에듀파인 주소, 로그인 후 AXGATE VPN Client 설치, 설치·실행·연결 Yes 확인, 기간 만료·패스워드 분실 시 재신청.
2. [서울교육청 EVPN 신청 방법](https://evpn.sen.go.kr/custom/evpn4_manual_application.html): 본인 신청 경로, 부서장 승인, 담당자 대리 신청. 브라우저 공개 본문 확인.
3. [서울 동부교육지원청 인증서 발급 안내](https://dbedu.sen.go.kr/CMS/civilapp/civilapp01/civilapp0105/civilapp010502/index.html): 검색에 노출된 공식 본문의 인증서 용도와 인사정보 등록 확인 내용. 직접 웹 수집은 서버 오류로 실패했으므로 세부 신청 절차는 옮기지 않았다.
4. [경기도교육청 2026 유치원 방과후 과정 운영 업무길라잡이](https://www.goe.go.kr/resource/goe/na/bbs_2675/2026/03/f57b2f27-0f5e-4673-af49-302b67f7d3d9.pdf): 인쇄 180·194쪽, PDF 188·202쪽의 아이디·인증서 로그인 → K-에듀파인 선택이라는 공통 흐름만 참고. 서울 내부 화면의 배치 근거로 사용하지 않는다.
5. [AI-SEN K-에듀파인 따라하기](https://chatbot.aisen.store/guide/): 접속 안내 구성의 참고 자료이자 지출관리시스템 따라하기 카탈로그·화면 이미지의 출처. 공개 JSON과 이미지를 원본 서버에서 연결해 표시한다. 제3자 앱 코드는 복제하지 않았다.

업무포털과 K-에듀파인의 인증 후 서울 내부 화면, 개인별 권한, 실제 로그인 성공 여부는 확인하지 못했다. 접속 안내의 예시 화면은 연습용으로 표시한다. 지출 업무의 메뉴 경로·설명·이미지는 공개 카탈로그 자료이며, 서울 최신 화면과 기관별 권한에 일치하는지 확인하지 못했다는 안내와 출처 링크를 표시한다.

## 검증

`npm run build`로 TypeScript 검사와 배포용 빌드를 함께 실행한다. 데이터 회귀 검증은 Node.js 24에서 `node --test scripts/edufine-access.test.mjs scripts/edufine-workflows.test.mjs`로 실행한다.

브라우저에서 연습과 확인 기록 분리, 단계 건너뛰기, 미완료 단계 재방문, 새로고침 복원, 접속 장소별 진도 분리, 좁은 화면 모드와 기존 용어 검색을 점검했다. 시험용 진도는 두 경로 모두 초기화했다.

접속 안내 초기 검증: TypeScript·빌드 성공, 접속 데이터 테스트 4개 통과. 데스크톱과 모바일에서 화면을 확인하고 기존 홈·K-에듀파인 화면을 메뉴로 왕복했다.

지출 확장 검증: 데이터 테스트 총 8개 통과. 카탈로그 형식 오류, 이미지 URL 제한, 원문 단계 번호 보존, 경로 검증 포함. 브라우저에서 K-에듀파인 → 지출 → 지출관리시스템 진입, 88개 업무 표시, 품의등록 검색, 화면 표시 클릭, 설명 이동과 확인 구분, 3개 화면 전환, 누락 확인 단계 복귀, 전체 완료와 다시 연습, 확대 시 내부 스크롤을 확인했다. Vite는 기존 500kB 초과 번들 크기 경고를 출력했으나 빌드는 성공했다. 별도 lint 설정은 없다.

추가 브라우저 검증: 분류와 검색 조합, 지출결의 화면, 목록 복귀 시 검색값 유지 확인. 320px·390px·767px·1280px·1440px에서 지출 화면을 검사했고, 320px·390px에서 확대해도 가로 스크롤은 이미지 영역 안에 머문다. 검사한 따라하기 페이지의 브라우저 오류·경고 로그는 없었다.
