# 사업관리시스템 따라하기

**에듀파인 따라하기 → 사업관리시스템 → 사업관리 따라하기 → 업무 선택**으로 진입한다. 기존 지출·수입·예산과 같은 검색·분류·화면 연습을 제공한다. 홈·K-에듀파인 용어사전·자료실과 공통 디자인은 유지한다.

- 목록: `/#edufine-access?activity=project`.
- 사업관리카드 학교별 조회 예시: `/#edufine-access?activity=project_003`.
- 출처: [AI-SEN 공개 사업관리 카탈로그](https://chatbot.aisen.store/data/catalogs/project.json).
- 2026-09-19 확인 시 원문 70개 항목 중 사용 가능한 69개 항목·69개 화면·204개 단계를 연결했다.

`project_001` 개요의 유일한 단계는 문서 변환 흔적(`<!-- PAGE BREAK`)이 포함된 손상된 설명이므로 제외한다. 이 검증은 사업관리 자료에만 적용한다. 일부 원문 설명은 중간에 끊겨 있으며(예: `project_032` 8번), 임의로 보완하지 않고 원본 화면을 함께 확인하도록 안내한다. 이름이 같은 항목을 구분할 수 있도록 목록에 원문 자료 페이지를 표시한다.

공통 화면은 유지하고 시스템 설정·진입 카드·허용 경로에 `project`를 추가했다. 이미지 경로는 출처의 `scenes/project_p숫자.png`만 허용하며 다른 시스템 자료와 섞이지 않도록 검증한다. 시스템별 자료·검색·진도는 분리된다.

원본 서버의 공개 자료를 직접 불러오는 학습용 기능이다. 실제 업무 등록·저장·결재를 실행하지 않는다. 원문의 페이지·단계 번호와 자료 누락 안내를 유지하며, 서울 최신 화면·기관별 권한의 일치 여부는 확인하지 못했다고 표시한다.

## 검증

- `npm run build`: TypeScript 검사·빌드 통과. 기존 500kB 초과 번들 경고 유지.
- `node --test scripts/edufine-access.test.mjs scripts/edufine-workflows.test.mjs`: 15개 테스트 통과.
- 실제 공개 자료 파싱: 사업 69개·204단계, 지출 88개·1,046단계, 수입 82개·1,009단계, 예산 17개·173단계. 기존 세 시스템의 항목·단계 수는 유지되며 모든 이미지 경로가 유효하다.
- 기존 `EdufinePage.tsx`의 SHA-256이 작업 전 백업과 동일하다.
- 브라우저에서 사업관리 메뉴, 69개 목록, 학교별 조회 검색 결과 10개, 원문 이미지, 화면 표시 클릭, 5개 단계 전체 확인과 완료 안내를 확인했다.
- 390px·320px 확대 시 가로 스크롤이 이미지 영역 안에 머문다. 검사한 페이지의 브라우저 오류·경고 로그 없음.
- 별도 lint·커버리지 도구는 프로젝트에 구성되어 있지 않다.
