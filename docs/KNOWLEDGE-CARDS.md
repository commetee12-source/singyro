본문 형식이 세 가지(START: 굵은 제목줄 절, HR·FIN·SCH: `- **항목:**` 한 줄 목록, INFO: `###` 소제목)라 파서를 형식별로 두었다. 새 카드가 다른 형식이면 스크립트가 요약·출처를 만들지 못하고 종료한다.

분야 매핑은 스크립트의 `CATEGORY` 표에 있다. 학교회계 심의·성립전예산·급식·운영위원회·발전기금·학적 카드 8장은 근무지 `school`, 나머지는 `all`.

### 반영하지 않은 것

- Critical 1(운영 JSON 스키마 `SEN-…-00000` 전환): 이 사이트는 자체 `Guide` 타입을 쓰므로 해당 없음. 원본 저장소 쪽 과제.
- Critical 2(카드별 소관부서 검토·검토자·검토일 기록): 검토가 실제로 이뤄지지 않았으므로 기록할 수 없다. 전건 `draft` 유지.
- 03-H-1·H-2·H-5(법령 매트릭스 수정): 매트릭스는 사이트에 없고, 대신 관련 카드 출처와 자료실 법령 목록에 정확한 제명·시행본을 넣었다.
- 04-E-05(Markdown 카드 경계)·E-07(통합 Markdown의 화성시 잔여어): JSON을 단일 원천으로 쓰므로 영향 없음.
- 문의 전화·내부 연락망·연도별 단가는 원문 그대로 두되 표준 주의문(`caution`)으로 미검증임을 밝힌다.

## 자료실 (`scripts/build-manuals.py`)

- xlsx 「자료목록」 58건 중 기존 손수 등록 항목과 겹치는 3건(S05 학교회계 지침, S06 교육비특별회계 지침, S20 인사운영 기본계획)은 제외하고 55건, 「법령근거」 34건 중 겹치는 3건(L01·L03·L26)을 제외한 31건 + 검증에서 추가된 4건 = 35건.
- 같은 게시판 URL을 쓰는 항목이 많다(BARO 학교업무지침 11건, 계약길잡이 5건 등). 설명에 「찾는 경로」를 넣어 게시판 안에서 어떤 제목을 찾을지 안내한다.
- 공식 원문 5건 중 파일이 확보된 것은 사이트에 올리지 않았다(저작권·내부 연락망). 공식 게시 페이지 링크 3건만 등록하고, 학교회계 지침·발전기금 요령은 기존/xlsx 항목으로 대신한다.
